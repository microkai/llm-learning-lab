# LLM 学习实验室

这是一个给“神经网络、深度学习、强化学习、LLM 底层架构”准备的学习中枢。

它的作用类似项目里的 `CLAUDE.md`：不是只放笔记，而是把学习路线、每个知识点应该产出的东西、代码注释标准、演示网页标准都固定下来。以后每开始一个知识点，就按这里的规则生成一个独立主题包。

## 怎么开始

1. 打开 [LEARNING.md](LEARNING.md)，看总路线。
2. 打开 [CHECKLIST.md](CHECKLIST.md)，勾学习进度。
3. 打开 [index.html](index.html)，从浏览器进入可视化学习首页。
4. 先学 [神经网络入门](topics/01-neural-network-basics/README.md)。

## 每个知识点都要产出什么

- `README.md`：这节课学什么、为什么重要、先学到什么程度；开头必须先讲目的和整体流程。
- `checklist.md`：本节课的掌握清单。
- `slides.html`：像 PPT 一样的图文讲义，包含技术栈选择原因和语法配套。
- `demo-web/index.html`：浏览器可打开的演示网页，图文都有，文字用中文转义和人话解释。
- `logic-map.html`：整体逻辑图，节点要能指到代码行号。
- `demo-project/`：实践 demo 项目，代码有学习型注释。
- `qa-notes.md`：学习中临时追问出的卡点沉淀笔记。

## Demo 代码注释规则

- 文档和讲义要先讲“目的”和“流程”，再解释术语和代码细节。
- 流程说明要把训练步骤拆清楚：前向传播、计算损失、反向传播、梯度下降、下一轮训练。
- 关键变量旁边要写清楚目的和含义，尤其是权重、偏置、损失、梯度、中间缓存、训练轮次这些变量。
- 变量注释要回答“它为什么存在”和“后面拿它做什么”，不要只复述变量名。
- 代码里出现标准库函数、内置函数、对象方法、框架 API、特殊运行入口时，第一次出现必须解释它在这里的意思，比如 `rng.uniform(-1.0, 1.0)` 要说明 `uniform` 是“均匀随机”，两个数字是随机范围。
- API 注释要回答三个问题：它来自哪里、它做什么、为什么这里要用它。
- 推导式、生成器表达式等压缩写法，要在旁边用普通循环展开。
- 注释优先写在代码现场，README 只记录规则，不单独维护变量表。

## 术语规则

英文术语可以出现，但第一次出现时必须带：

```text
中文名（英文名，白话：一句人话解释）
```

例子：

```text
自注意力机制（self-attention，白话：一句话里的每个词都去看看别的词，再决定自己该表达什么）
```
