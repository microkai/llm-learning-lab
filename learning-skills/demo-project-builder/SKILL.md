# Demo Project Builder

用于给某个知识点制作实践项目。

## 技术栈选择原则

- 概念很底层：优先从零实现，少依赖。
- 需要矩阵计算：优先 Python + NumPy。
- 需要真实深度学习训练：优先 PyTorch。
- 需要浏览器互动：优先 HTML + CSS + JavaScript。
- 需要强化学习环境：优先 Gymnasium 或成熟环境库。
- 需要 3D 或复杂可视化：优先 Three.js。

## 代码注释规则

demo 的 `README.md` 开头必须先讲目的和流程，再进入术语、API 和关键行号。

关键代码附近要写学习型注释：

```text
总流程：前向传播、计算损失、反向传播、梯度下降、下一轮训练。
目的：这一段解决什么问题。
语法：初学者容易不懂的语法是什么。
连接：它在逻辑图里属于哪一步。
展开：推导式、生成器表达式等压缩写法的等价普通循环。
API：第一次出现的标准库函数、内置函数、对象方法、框架 API、特殊运行入口的来源、作用和当前用途。
```

## 引用 GitHub 项目规则

可以引用 GitHub 项目，但必须先确认：

- 项目最近是否维护。
- 许可证是否允许学习使用。
- 安装步骤是否适合当前机器。
- 是否比从零实现更适合这个知识点。

引用后要在 demo 的 `README.md` 写明来源和改动。
