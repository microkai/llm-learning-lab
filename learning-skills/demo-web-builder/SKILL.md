# Demo Web Builder

用于给某个知识点制作图文互动网页。

## 设计规则

- 页面必须能静态打开，不要求本地服务。
- 页面必须有图形表达，可以是 CSS 图、Canvas 图、SVG 图或合适的网络图片。
- 文字解释必须是中文，并包含人话解释。
- 控件要服务学习目标，比如滑块调权重、按钮切换步骤、开关显示遮罩。
- 不做营销页，第一屏直接是学习体验。

## 推荐技术栈

- HTML：承载结构。
- CSS：画图、布局、状态样式。
- JavaScript：做交互。

选择理由：学习型互动网页通常不需要复杂框架，原生网页技术最轻，打开就能看，也方便把“页面元素”和“代码逻辑”对应起来。

## 完成标准

- 至少一个可交互控件。
- 至少一个视觉图。
- 关键变量能在页面上即时变化。
- 文案不只给定义，要说“这个东西解决什么问题”。
