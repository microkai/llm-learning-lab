# Question Note Hook

用于把学习过程中临时追问出的关键理解沉淀到主题笔记。

## 触发场景

当用户出现这些表达时使用：

- “把我刚问的点放到笔记里”
- “这个点记一下”
- “做个 hook”
- “以后这种问题沉淀下来”
- “把这些追问整理一下”

## 存放位置

优先写入当前主题目录：

```text
topics/当前主题/qa-notes.md
```

如果当前主题还没有 `qa-notes.md`，先创建。

## 写法要求

1. 不要把对话逐字搬进去，要整理成可复习的知识点。
2. 每个小节标题必须是用户真实卡过的点，比如：
   - `grad 存在哪里`
   - `forward 是模型的计算路线`
   - `nn.Linear 自动创建 weight 和 bias`
3. 每个小节优先按这个结构写：
   - 一句话结论。
   - 人话解释。
   - 必要代码片段。
   - 容易误解的地方。
4. 英文术语第一次出现必须带中文名和人话解释。
5. 如果某个追问已经影响到学习路线，要同步更新主题 `README.md` 或 `checklist.md`。

## Hook 行为

当用户继续在某个主题里追问，并且问题明显是理解卡点时，助手应主动判断是否需要追加到 `qa-notes.md`。

如果用户没有明确要求写文件，可以先口头解释；如果用户说“记一下”“放到笔记里”“这个也沉淀”，就直接更新 `qa-notes.md`。

## 完成标准

- `qa-notes.md` 能独立阅读。
- 新增内容能从主题 `README.md` 找到入口。
- 不打断当前学习主线，只沉淀关键卡点。
