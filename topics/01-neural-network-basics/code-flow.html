主题说明 PPT 讲义 逻辑图 互动网页 源码

训练时的 forward

用当前参数先答题，得到 prediction 和中间结果。后面要用这些结果算 loss 和梯度。

预测时的 forward

训练完以后也要答题，但只拿 prediction，不计算 loss，也不修改参数。

区别一句话

训练 = forward + loss + backward + update；预测 = forward。

所以你看到“训练完之后做前向传播”是正常的。 `forward()` 是模型的通用答题函数：训练时用它答题并留下中间过程，预测时也用它答题但不再学习。
