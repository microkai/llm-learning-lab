先看目的和流程

前向传播

用当前参数先答题，把输入算成 prediction。

计算损失

把 prediction 和参考答案比较，得到错得多不多。

反向传播

从 loss 往回算，找每个参数对错误的责任。

梯度下降

按负梯度方向改参数，让下一轮 loss 更低。

重复训练

一轮轮答题、算错、算责任、改参数。

最终目标

找到一组参数，让异或样本预测足够准。

术语先翻成人话

神经元

白话：一个小计算器。它把输入乘权重，加偏置，再输出一个信号。

权重

白话：输入的音量旋钮。权重大，这个输入对答案影响更大。

偏置

白话：基础倾向。没有明显输入时，神经元也可以偏向开或关。

前向传播

前向传播（forward pass，白话：从输入一路算到答案）只负责算，不负责学习。

在代码里看第 132 行：输入先进入隐藏层，再进入输出层，最后得到预测分数。

输入 * 权重 + 偏置 = 原始分数
激活函数(原始分数) = 输出分数
输出分数 >= 0.5，就判断为 1

为什么需要损失

损失函数（loss function，白话：把错得多不多变成数字）让模型知道自己离答案有多远。

本节用的是“差距平方的一半”。平方会放大大错误，方便模型优先修正明显错误。

error = prediction - target
loss = 0.5 * error * error

反向传播在做什么

1. 输出层先认错

预测离目标越远，输出层要改得越明显。

2. 隐藏层分摊责任

隐藏层没有直接答案，只能根据输出层传回来的错误调整。

3. 学习率控制步子

步子太小会慢，步子太大可能越改越乱。

为什么这个技术栈适合

Python 标准库

不安装依赖。适合把权重、损失、梯度更新全写出来。

HTML + CSS

适合画节点、层、信号流，让抽象概念变成图。

JavaScript

适合滑块互动，拖一下就能看到输出怎么变。

语法配套

  • `class`：把网络的数据和动作包在一起。
  • `for` 循环：反复更新每个权重。
  • `enumerate`：同时拿到序号和值，适合改列表里的对应位置。
  • `list[float]`：表示这里期待一组小数。
for index, hidden_value in enumerate(hidden_outputs):
    gradient = output_delta * float(hidden_value)
    self.output_weights[index] -= learning_rate * gradient

动手改这几个参数

训练轮数

`epochs=8000`。改小会看到模型还没学够。

学习率

`learning_rate=0.7`。改太小会慢，改太大可能不稳。

隐藏神经元

`hidden_size = 4`。改成 2 可能更容易卡住。
