非线性：为什么 Linear 后面要接 ReLU

如果模型只有 Linear，它像一把直尺，只会画直线；加上 ReLU 后，它能用很多小折线拼出“过了某个条件才明显变化”的业务规律。

先用业务类比理解

Linear：固定加权

像给每个因素打分再求和。商品件数多一点，风险就按固定比例加一点。它简单、稳定，但只能表达直线关系。

ReLU：触发开关

像业务阈值。没到截单压力时，这个风险信号可以当 0；一旦超过阈值，它才开始明显影响结果。

非线性：允许拐弯

真实业务常常不是一条直线。比如少量订单很好处理，但仓库接近满负载后，延迟风险会突然变陡。

它和神经网络的关系

没有 ReLU

Linear 接 Linear，数学上还是能合并成一个 Linear。就像你连续用几把直尺画线，最后仍然是一条直线。

加了 ReLU

ReLU 把一部分信号截断为 0，等于给模型加了“条件开关”。这些开关让模型能表达分段规则。

多层网络

很多 Linear + ReLU 叠起来，就像很多小业务规则组合：库存低、仓库忙、快到截单、商品复杂，这些信号可以互相影响。

关键记法

Linear 负责加权汇总，ReLU 负责让规则能拐弯。非线性不是玄学，它就是让模型不被限制在一条直线上。
