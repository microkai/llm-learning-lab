为什么要 zero_grad

梯度默认会累加。下一轮训练前要清空旧梯度，不然上一轮责任会混进来。

为什么要 backward

它沿计算图倒着走，把 loss 对每个参数的影响算出来。

为什么要 step

它用 `参数 -= 学习率 * 梯度` 真正修改参数。
